# JSON Learning Journey

This repository documents my learning journey with **JSON (JavaScript Object Notation)** through theoretical concepts and practical implementations using Python and JavaScript. I am exploring how JSON structures, stores, and exchanges data between applications, and how it is commonly used in APIs and modern software development.

## Learning Objectives

- Understand JSON and its importance in modern application development.
- Learn JSON syntax, structure, and data types.
- Work with key-value pairs, arrays, objects, and nested structures.
- Understand the difference between JSON and JavaScript objects.
- Convert JSON strings into programming language objects and vice versa.
- Practice handling JSON data using Python and JavaScript.

## Topics Covered

- Introduction to JSON
- JSON Syntax and Rules
- Key-Value Pairs
- JSON Data Types
  - String
  - Number
  - Boolean
  - Array
  - Object
  - Null
- Nested JSON Objects
- JSON Validation using JSONLint
- JSON vs JavaScript
- JSON in Python
  - `json.loads()`
  - `json.dumps()`
- JSON in JavaScript
  - `JSON.parse()`
  - `JSON.stringify()`

## Practical Implementations

### Python
- Converting JSON strings into Python dictionaries using `json.loads()`.
- Converting Python dictionaries into JSON strings using `json.dumps()`.
- Accessing values from dictionaries and nested objects.

### JavaScript
- Parsing JSON strings using `JSON.parse()`.
- Converting JavaScript objects into JSON strings using `JSON.stringify()`.
- Accessing values from nested objects and arrays.
